Super Simplified / 01

AI'ed (AI things)

These ideas apply to LLMs and today’s AI technologies. The shortest useful mental model is: a model provides the intelligence, an agent runs a loop, a harness gives it a body, and MCP connects it to the outside world.

01 / MODEL

Brain

A huge matrix of weighted numbers.

02 / AGENT

Loop

Uses the model to observe, decide, and act.

03 / HARNESS

Body

The tools and structure around the model.

04 / MCP

Connection

A USB-C-like bridge to external services.

The five building blocks.

They are related, but they are not interchangeable. Each one answers a different question about how an AI system works.

01

AI Agent

AI Agent: loop

An agent is the repeating loop that uses a model to interpret a situation, choose a next step, take an action, inspect the result, and continue.

02

AI Model

A huge matrix of (weighted) numbers.

An AI model is like the brain for a human. It contains the learned capability, but it does not perform tasks on its own.

03

Model versus agent

Models are like the brain; agents are like hands, feet, and the rest of the working body.

Models cannot perform on their own. They use agents to work on their behalf—the agent turns capability into an ongoing process.

04

Skills

A long list of prompts.

Skills package repeatable instructions for an agent. They are prompts organized so the agent can apply a known way of working.

05

Harness

Agent = Model + Harness

Think of a self-driving car. The entire self-driving car is the complete “agent”: a unified entity that can navigate a city because its abstract brain—the model—is plugged into its mechanical and software body—the harness.

06

MCP

Like a USB-C connection.

MCP can connect any LLM—Claude, ChatGPT, or others—to external services such as databases and document-processing systems.

One picture to keep.

Start with the model, put it in a loop, give the loop a body, and connect that body to the services it needs.

Model + Harness → Agent loop   |   MCP → External services

Self-driving car

The model is the abstract brain. The harness is the sensors, controls, software, and mechanical body. The agent is the complete car navigating the road.

USB-C

MCP is the standardized connection idea: the LLM does not need to become the database or document system. It needs a reliable way to connect to one.
